# Role Play: Choosing an OpenShift Setup

### Scenario
A teammate, Sarah, wants to start developing a Python application. She asks for your advice on which OpenShift environment she should use.

### Options
1. **OpenShift Local (CRC)**
2. **Developer Sandbox**
3. **Full Enterprise Cluster**

### Discussion Points
- If Sarah has a high-end laptop and needs to work offline? **(Use CRC)**
- If Sarah wants to start in 5 minutes without installing anything? **(Use Sandbox)**
- If Sarah needs to test a feature that requires Cluster Admin permissions? **(Use CRC or a dedicated Lab Cluster)**
