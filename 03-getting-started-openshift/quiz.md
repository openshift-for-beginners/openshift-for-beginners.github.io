# Knowledge Check: Getting Started

**1. What is the CLI command to start OpenShift Local?**
- [ ] `oc start`
- [x] `crc start`
- [ ] `openshift up`

**2. Which Web Console perspective is used to see the Topology graph of an application?**
- [x] Developer Perspective
- [ ] Administrator Perspective

**3. What is the main limitation of the Red Hat Developer Sandbox?**
- [ ] You cannot use the CLI.
- [x] You do not have Cluster Administrator access.
- [ ] You can only run one pod.
