# Red Hat Developer Sandbox

The **Developer Sandbox** is a "zero-install" way to learn OpenShift.

## Key Features
- **Cost:** Free.
- **Duration:** 30 days (renewable).
- **Environment:** Shared cluster, but you get your own isolated projects.
- **Pre-configured:** Includes popular developer tools and templates.

## Limitations
- **No Cluster Admin:** You cannot change cluster-wide settings.
- **Shared Resources:** There are limits on CPU, RAM, and storage.
- **Hibernation:** If not used, pods may be spun down to save resources.
