# OpenShift UI Overview

The OpenShift console is designed for two distinct roles.

## Developer Perspective
- **Topology:** See a visual graph of all components in your project.
- **Add:** Multiple ways to deploy (From Git, Container Image, Dockerfile, or Catalog).
- **Builds:** Monitor the progress of Source-to-Image (S2I) builds.
- **Observe:** View logs and basic metrics.

## Administrator Perspective
- **Home:** Dashboard for cluster health and status.
- **Operators:** Manage installed extensions (e.g., Service Mesh, Serverless).
- **Networking:** Manage Ingress, Routes, and Services.
- **Storage:** Create Persistent Volume Claims (PVCs).
