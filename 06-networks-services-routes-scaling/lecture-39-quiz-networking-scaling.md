# Lecture 39: Quiz - Networking and Scaling

**1. Which object provides a stable internal IP address for a group of Pods?**
- [ ] Route
- [x] Service
- [ ] PodStream

**2. Which TLS termination type allows the encrypted traffic to reach the Pod without being decrypted by the OpenShift Router?**
- [ ] Edge
- [x] Passthrough
- [ ] Re-encryption

**3. What is the name of the Kubernetes component that automatically adjusts the number of Pod replicas based on CPU usage?**
- [ ] Vertical Pod Autoscaler
- [x] Horizontal Pod Autoscaler (HPA)
- [ ] Cluster Scaler

**4. True or False: Horizontal scaling means adding more CPU/RAM to an existing Pod.**
- [x] False (That is Vertical scaling).
