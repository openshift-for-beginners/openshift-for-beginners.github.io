# Lecture 12: Deploying Applications - Web Console

The OpenShift Web Console provides a streamlined **Developer Perspective** for creating and managing applications visually.

### The +Add Flow
The "+Add" menu includes:
- **From Git:** Points to a source repository, detects the language, and builds the app.
- **Container Image:** Deploys an existing image from a registry like Quay.io or Docker Hub.
- **Samples:** Pre-configured templates to see how OpenShift works.

### Topology View
After deployment, the **Topology View** provides a visual graph. It allows you to check Pod status, access the Route URL, and scale pods up or down visually.
