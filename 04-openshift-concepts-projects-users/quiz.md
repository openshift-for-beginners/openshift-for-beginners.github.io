# Knowledge Check: Projects and Users

**1. What is the OpenShift-specific resource that acts as a wrapper around a Kubernetes Namespace?**
- [ ] Folder
- [x] Project
- [ ] Workspace

**2. Which command is used to create a new project via the CLI?**
- [ ] `oc create namespace`
- [x] `oc new-project`
- [ ] `oc start-project`

**3. If you want an application (Pod) to have permission to list other pods in its project, what type of user should you use?**
- [ ] Regular User
- [x] Service Account
- [ ] Admin User

**4. True or False: OpenShift's Web Console "Topology" view is found in the Administrator Perspective.**
- [x] False (It is in the Developer Perspective).
