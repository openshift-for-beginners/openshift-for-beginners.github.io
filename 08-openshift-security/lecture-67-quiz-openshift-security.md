# Lecture 67: Quiz - OpenShift Security

**1. Which object is used to grant a "ServiceAccount" permissions within a project?**
- [ ] UserBinding
- [x] RoleBinding
- [ ] GroupPolicy

**2. Where should you store a database password for a pod?**
- [ ] ConfigMap
- [x] Secret
- [ ] Dockerfile

**3. Which OpenShift security component prevents a container from running as the 'root' user by default?**
- [ ] Network Policy
- [ ] RBAC
- [x] Security Context Constraints (SCC)

**4. True or False: Base64 encoding is a secure way to encrypt sensitive data.**
- [x] False (It is only encoding, not encryption).
