# Lecture 25: Demo - Route

### 1. Expose a Service
The fastest way to create a Route via the CLI is to "expose" an existing service:
```bash
oc expose svc/<service-name>
```

### 2. View the Route URL
To see the public URL generated by OpenShift:
```bash
oc get route
```

### 3. Describe the Route
To see details about where the traffic is pointing and TLS settings:
```bash
oc describe route <route-name>
```

### 4. Testing
You can simply copy the `HOST/PORT` value from the `oc get route` output and paste it into your browser to access your application.
