# Lecture 1: Course Introduction

## Overview

This lecture introduces the course, its learning path, and what to expect in the upcoming sections. It acts as a roadmap for the overall OpenShift learning journey.

## Learning Objectives

After this lecture, I should be able to:

- Understand the structure of the course
- Know the major topics covered
- Identify the practical and conceptual areas of OpenShift
- Set expectations for labs, demos, quizzes, and role plays

## What This Course Covers

Based on the full outline, this course includes:

- OpenShift basics
- Docker and Kubernetes prerequisites
- OpenShift installation methods
- Projects and users
- Builds and deployments
- Networking, services, routes, and scaling
- Storage and templates
- Security concepts
- Appendix topics such as GitLab and CI/CD fundamentals

## My Understanding

This course appears designed for beginners who want a practical introduction to OpenShift. It starts with foundational concepts, then gradually moves into hands-on topics such as:

- deploying applications
- managing projects
- working with image streams
- creating builds
- exposing apps through routes
- scaling workloads
- configuring storage
- applying RBAC and security controls

## Why This Course Matters

OpenShift is an enterprise Kubernetes platform. Learning it helps in understanding:

- containerized application deployment
- platform engineering basics
- Kubernetes-based workflows
- DevOps and CI/CD integration
- security and multi-tenant cluster management

## Expected Learning Flow

The progression of the course looks like this:

1. Understand OpenShift basics
2. Learn Docker and Kubernetes prerequisites
3. Install or access OpenShift
4. Deploy applications
5. Learn OpenShift-specific objects and workflows
6. Work with networking and scaling
7. Explore storage and templates
8. Learn security and access control
9. Wrap up with supporting DevOps concepts

## My Learning Goals

I can use this section to define my own goals for the repo.

### Personal Goals
- Build a strong foundation in OpenShift
- Learn the difference between OpenShift and Kubernetes
- Practice both UI and CLI workflows

## Key Takeaways

- This course is structured for gradual learning
- It combines theory, demos, quizzes, and role-play scenarios
- OpenShift is taught both as a platform and as a practical deployment tool
- The course prepares learners for real-world cluster usage
